# Clase - Librerías, Frameworks y Gestores de Paquetes

Sitio de diapositivas hecho con Vite + React + TypeScript.

## Ejecutar

```bash
npm install
npm run dev
```

## Controles

- Flecha derecha / espacio: siguiente diapositiva
- Flecha izquierda: diapositiva anterior
- F: pantalla completa
- Home: primera diapositiva
- End: última diapositiva

## Contenido

Clase independiente sobre:

- librerías;
- frameworks;
- diferencia entre librería y framework;
- dependencias;
- gestores de paquetes;
- package.json;
- scripts;
- node_modules;
- lockfiles;
- Vite;
- TypeScript;
- cómo iniciar un proyecto moderno desde cero.

## Nota sobre logos

Los logos se cargan desde CDNs públicos de Devicon y Simple Icons para identificación educativa de las tecnologías.
Si el equipo donde se proyecta no tiene internet, las tarjetas siguen mostrando el nombre de la tecnología.
