# Clase de Testing - Teoría

Presentación web hecha con Vite + React + TypeScript + Framer Motion.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Controles

- Flecha derecha / espacio: siguiente diapositiva
- Flecha izquierda: diapositiva anterior
- F: pantalla completa
- Home: primera diapositiva
- End: última diapositiva

## Contenido

- qué es testing;
- por qué se testea;
- error, defecto, bug y falla;
- QA vs testing;
- niveles de prueba;
- testing unitario, integración, sistema y aceptación;
- caja negra, caja blanca y caja gris;
- pruebas manuales y automatizadas;
- casos de prueba;
- bug reports;
- scripts de testing modular;
- ejemplos de código;
- buenas prácticas y límites del testing.
