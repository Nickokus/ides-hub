# Clase interactiva: Design Systems

Presentación para Interfaz de Usuario desarrollada con Vite + React + TypeScript.

## Ejecutar

```bash
npm install
npm run dev
```

## Controles
- Flecha derecha / Page Down / Espacio: siguiente
- Flecha izquierda / Page Up: anterior
- Home / End: inicio / final
- F: pantalla completa

## Incluye
- botón con hover, click, loading y success
- variantes Primary / Secondary / Danger
- estados de componentes
- Main Component e instancias
- Sidebar reutilizable con estado activo
- Design Tokens
- componentes anidados
- UI Kit vs Design System
- documentación y actividad final
