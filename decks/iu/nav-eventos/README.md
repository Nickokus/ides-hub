# Navegación y eventos · Presentación interactiva

Proyecto Vite + React + TypeScript para presentar una clase de Interfaz de Usuario.

## Ejecutar

```bash
npm install
npm run dev
```

Abrí la URL que muestra Vite, normalmente `http://localhost:5173`.

## Controles

- Flecha derecha / PageDown / Espacio: siguiente diapositiva
- Flecha izquierda / PageUp: anterior
- Home: primera
- End: última
- F: pantalla completa

## Demos incluidas

- Evento → respuesta → estado → feedback
- Tipos de navegación
- Mapa de rutas
- Simulación de app navegable
- Inspector de eventos
- Estados de navegación
- Feedback de éxito/error
- Navegación con teclado y foco visible
- Historial y volver
- Modal contextual
- Navegación mobile
- Comparación de mala/buena navegación
