# Psicología UX/UI — Presentación interactiva

## Ejecutar
```bash
npm install
npm run dev
```

## Controles
- → / PageDown / Espacio: siguiente
- ← / PageUp: anterior
- Home: primera
- End: última
- F: pantalla completa

## Demos incluidas
- Modelos mentales: convención familiar vs rota
- Carga cognitiva: formulario completo vs dividido en pasos
- Ley de Hick: 3 opciones vs 12 opciones
- Ley de Fitts: targets pequeños, medianos y grandes
- Ley de Jakob: símbolos familiares vs invertidos
- Von Restorff: un destacado vs todo destacado
- Reconocimiento vs recuerdo
- Progressive Disclosure
- Peak-End Rule
