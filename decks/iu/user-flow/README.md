# User Flow profesional

Presentación interactiva original de Interfaz de Usuario.

Tecnologías: Vite + React + TypeScript + Framer Motion + React Flow.

## Controles

- Flecha derecha / espacio: siguiente diapositiva
- Flecha izquierda: diapositiva anterior
- F: pantalla completa
- Home / End: inicio y final
- En la vista de flujo: zoom, pan, selección de nodos y pantalla completa del gráfico
